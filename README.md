# Jamesy0ung Tap

## How do I install these formulae?

`brew install jamesy0ung/tap/<formula>`

Or `brew tap jamesy0ung/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jamesy0ung/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
